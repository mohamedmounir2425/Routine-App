## معنى الحالات

- **موجود محليًا:** الكود يخزنه في IndexedDB أو localStorage؛ لا يعني وصوله لجهاز آخر.
- **موجود سحابيًا:** الجدول موجود في public؛ لا يعني أن جميع الحقول أو عمليات المزامنة تعمل.
- **مقترح:** احتياج متفق عليه أو تصميم مبدئي لم ينفذ، وأسماء الجداول المقترحة قابلة للتغيير.

تفاصيل الأعمدة السحابية في المرجع المشترك حتى لا تتكرر بنسخ مختلفة داخل كل مساحة. تعريفات TypeScript المشار إليها هي مرجع الحقول المحلية الكامل.

## تحديث التوثيق

مع كل ميزة: حدّث ملف المساحة، وحالة المزامنة، وقواعد الصلاحيات والنسخ الاحتياطي. مع كل تغيير backend: احفظ migration SQL راجعها واختبرها، ثم حدّث لقطة البنية. ملفات هذه المرحلة ليست schema dump أو migrations قابلة للتطبيق، ولا تشمل بيانات المستخدمين أو أسرار الاتصال.
