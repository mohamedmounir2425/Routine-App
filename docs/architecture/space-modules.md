# فصل المساحات والمكونات المشتركة

كل مساحة تملك واجهاتها وحالتها ومنطقها، ويجمعها تطبيق React واحد. المشاركة تتم عبر واجهات معلنة ومكونات عامة. هذا فصل للكود والمسؤوليات؛ التخزين والحساب والمزامنة ما زالوا بنية مشتركة، وليس لكل مساحة إصدار أو نشر مستقل.

## مكان العمل

- `src/app`: إعدادات التطبيق والثيم والتثبيت. لا يحمّل مكتبة التمارين.
- `src/features/health`: لوحة الصحة والتمارين وخطط التدريب والمشغل والإحصائيات والتذكيرات وحالة الصحة وخدماتها.
- `src/features/home`, `work`, `worship`, `plans`: كود كل مساحة.
- `src/features/today`, `progress`: واجهات التجميع والتكامل بين المساحات.
- `src/features/spaces`: دليل المساحات وشاشة المهام العامة.
- `src/shared/ui`: مكونات عرض عامة مستقلة عن بيانات المساحات.
- `src/shared/tasks`: قواعد المهام النقية المشتركة.
- `src/db`, `types`, `context`, `i18n`, `utils`: البنية المشتركة الحالية. لم تتغير أسماء قواعد البيانات أو الجداول أو النسخ الاحتياطية.

## واجهات التعامل

- `index.ts`: نقطة الدخول لواجهة المساحة، وتُحمّل واجهات المساحات عند فتح مساراتها من `src/App.tsx` فقط.
- `public.ts`: خدمات أو عقود محددة للتكامل؛ تجنب تصدير واجهة المساحة منه.
- `ui.ts`: أجزاء واجهة مقصود مشاركتها، مثل شاشة مهام المساحات العامة.
- داخل المساحة مسموح استخدام ملفاتها مباشرة. خارجها يتم الاستيراد من نقاط الدخول الثلاث فقط، بما في ذلك dynamic imports وtype imports.
- المساحات التخصصية (`home`, `work`, `worship`, `health`, `plans`) معزولة عن بعضها: لا تستورد مساحة تخصصية من مساحة تخصصية أخرى، ولا تستورد من واجهات التجميع (`today`, `progress`). التجميع يقرأ من `public.ts` للمساحات في اتجاه واحد فقط.
- `shared` لا يستورد المساحات أو حالة التطبيق أو قاعدة البيانات. والميزات لا تستورد `app`.
- اختبارات التكامل وحدها مسموح لها فحص الملفات الداخلية للمساحات.

التحقق موجود في `npm run check:boundaries` ويعمل كذلك قبل البناء والاختبار وlint. يقرأ TypeScript لحل المسارات، وبالتالي يكتشف الوصول للملفات الداخلية عبر المسارات النسبية وaliases المعرفة في إعدادات TypeScript.

## Tailwind والمكونات المتكررة

اكتب كلاسات Tailwind مباشرة في `className` داخل JSX. استخرج مكون React عند تكرار تصميم بين ملفات. لا تنشئ CSS Modules أو كلاسات CSS للتصميم الجديد، ولا تستخدم `@apply` لتجميع الكلاسات.

ملفات `*.tokens.css` مسموحة لتعريف قيم الألوان والخطوط والأحجام وإعداد `@theme`. أي CSS قديم موجود في قائمة انتقالية محددة في `scripts/space-boundaries.mjs`؛ يتم تقليل هذه القائمة أثناء نقل الشاشات، ولا تُضاف إليها ملفات جديدة. ملفات التوافق القديمة لم تُحذف بالكامل في هذه الدفعة.

استخدم Ant Design tokens لتنسيق مكوناته، و`classNames` للأجزاء الداخلية المدعومة. يجب أن تبقى تخصيصات Tailwind داخل ملف المكون. الألوان الخاصة بالمنزل تبقى في ثيم المنزل؛ المكون العام يرث أقرب `ConfigProvider` ولا يستورد ألوان المنزل أو منطقه.

`shared/ui/UIProvider.tsx` يضبط ثيم الأساس واللغة والاتجاه من خصائص يمررها التطبيق؛ يقرأ قيمه من `shared/theme/applicationTheme.ts`. بذلك يعمل الجدول المشترك في أي مساحة مع وضع التطبيق الداكن/الفاتح وRTL/LTR حتى إن لم يكن للمساحة ثيم خاص. `HomeUIProvider` يحتفظ بتخصيص المنزل داخل هذا الأساس.

## الجدول المشترك

`src/shared/ui/DataTable.tsx` هو مدخل الجداول المخصصة. يحتفظ بـTypeScript generics وخصائص Ant Design الأصلية: الأعمدة، الفرز، الفلترة، التحديد، الترقيم، التوسيع، semantic classNames وloading. الأحجام قابلة للضبط عبر `size`، والثيم يورث من المساحة.

استُخدم في جدول المخزون وجدول الإدخال الجماعي وجدول معاينة الاستيراد. المساحة تملك البيانات والأعمدة وقواعد الصلاحية والحفظ والتراجع. أي تعديل على التنسيق الافتراضي المشترك يُراجع في المستهلكين الثلاثة. اختلاف مساحة واحدة يُمرَّر كخاصية واضحة أو تخصيص داخل أعمدتها؛ لا يحتاج المكون إلى `spaceId` أو شروط تخص المخزون والتمارين.

## تكامل الصحة

`HealthProvider` يملك حالة الصحة. `useHealthIntegration` يتيح للتطبيق ملخص اليوم والسلسلة وتشغيل تمرين. الواجهات لا تمرر تفاصيل التمارين والخطط من `App.tsx` بعد الآن. يتم تحميل الكتالوج الكامل عند دخول الصحة، أو قراءة تمارين التشغيل عند طلب تشغيل جلسة من Today. اللاعب ومحرر الروتين يُحمّلان عند الحاجة.

ملخص الصحة والتذكيرات يعملان في الخلفية. فشل قراءة بيانات الصحة يظهر داخل مساحتها، وفشل تشغيل جلسة يظهر كرسالة إجراء. `SpaceBoundary` يحافظ على شريط التنقل عند فشل عرض إحدى المساحات. تهيئة قاعدة الحساب أول مرة والمزامنة ما زالتا خدمات مشتركة.

## التحقق

- `npm test`: سياسة الفصل والستايل، ثم سيناريوهات البيانات والمزامنة والمخزون والصحة داخل fake-indexeddb.
- `npm run build`: حدود المساحات وTypeScript وبناء الإنتاج.
- عند تعديل الجدول أو ثيمه: راجع المخزون والإدخال ومعاينة الاستيراد، والموبايل والكمبيوتر، والثيمين.
- راجعت هذه الدفعة على الكمبيوتر في الثيم الداكن: جدول المخزون والإدخال ومعاينة الاستيراد، مكتبة الصحة والخطط، وفتح اللاعب من Today. لم تحفظ بيانات الاختبار في الواجهة. تعطل اتصال أداة المتصفح قبل اكتمال فحص الموبايل والثيم الفاتح.
- توجد أخطاء lint سابقة في المشروع؛ تقارن نتيجة التغييرات بالنتيجة السابقة، ولا تعتبر وجودها نجاحًا كاملًا لفحص lint.
