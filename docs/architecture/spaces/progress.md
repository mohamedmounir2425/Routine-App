# التقدم العام

الحالة: مساحة عرض مشتقة من بيانات بقية المساحات؛ المسار /progress/* وليس قيمة إضافية ضمن LifeSpaceId.

## الموجود والبنية

يعرض مؤشرات وتوجهات أسبوعية وإنجاز الخطط وأنشطة العمل والصحة والعبادة وفق السجلات المتاحة. مصدره [progressAggregator](../../../src/features/progress/progressAggregator.ts) و[progressTypes](../../../src/features/progress/progressTypes.ts)، مع حسابات مجال العبادة والعمل والخطط.

لا يوجد جدول Supabase خاص بالتقدم ضمن الجداول الستة الحالية. المؤشرات مشتقة من المهام والمراحل وسجلات التمرين والأذكار وlocalStorage، وبالتالي نقص مزامنة المصدر يؤدي إلى اختلاف النتيجة بين جهازين. لا تعتبر لوحة التقدم نسخة احتياطية أو مصدرًا مستقلًا للإنجاز.

## نقل .NET

انقل سجلات المصدر أولًا ثم أعد حساب المؤشرات. خدمة التقارير تقرأ ما تسمح به صلاحيات المستخدم وتحدد نطاق اليوم والأسبوع والمنطقة الزمنية. لا تجمع إنجاز مورد مشترك مرتين، ولا تكشف بيانات العمل الخاصة عند مشاركة هدف. أي cache أو ملخص سحابي مستقبلي مشتق وقابل لإعادة البناء؛ لم ينفذ هنا.
